# Execution-path aggregate gate (2026-06-13)

- Added `scripts/validate_execution_path_gate.py` as a bounded local aggregate validator for the planner-to-adapter-to-signer/Web3 execution path.
- The gate emits schema `arbyclaw.execution_path_aggregate_gate.v1` and composes 18 local-only validators:
  - `validate-opportunity-planner-handoff`
  - `validate-strategy-constrained-planner`
  - `validate-execution-planner-audit --workspace <fresh-dir>`
  - `validate-policy-decision-audit --workspace <fresh-dir>`
  - `validate-destination-boundary-audit --workspace <fresh-dir>`
  - `validate-execution-adapter-audit --workspace <fresh-dir>`
  - `validate-signer-boundary-audit --workspace <fresh-dir>`
  - `validate-signer-runtime-isolation`
  - `validate-signer-authorization-envelope`
  - `validate-web3-nonce-reservation`
  - `validate-web3-unsigned-payload-review`
  - `validate-web3-pre-sign-safety`
  - `validate-web3-broadcast-readiness`
  - `validate-web3-unsigned-transaction-construction`
  - `validate-web3-provider-nonce-reconciliation`
  - `validate-web3-raw-transaction-serialization-review`
  - `validate-web3-broadcast-adapter-control-review`
  - `validate-web3-sandbox-live-discrepancy-calibration`
- It checks exact pass/status outputs plus side-effect denials across planner, policy, destination, adapter, signer, and Web3 reviews, and confirms all aggregate unsafe fields are false (`external_calls_performed`, `external_submission_performed`, `signer_material_loaded`, `plaintext_decrypted`, `signing_performed`, `broadcast_performed`, `live_execution_performed`, `production_ready`).
- Wired CI to run `python3 scripts/validate_execution_path_gate.py` and removed the now-redundant standalone CI steps for opportunity planner handoff, strategy-constrained planner, policy decision audit, execution adapter audit, destination boundary audit, signer boundary/runtime isolation/authorization, and the standalone Web3 non-broadcast review commands because the aggregate now enforces them together.
- Updated `scripts/validate_structure.py`, `STRUCTURE_MANIFEST.md`, `ROADMAP.md`, `HANDOFF_CONTEXT.md`, `ARCHITECTURE.md`, and `PRODUCTION_GAP_TRACKER.md` so the repo now describes a local execution-path aggregate gate accurately.
