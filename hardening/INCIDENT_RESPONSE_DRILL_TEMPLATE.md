2. Freeze live execution paths if any exist in the external environment.
3. Preserve audit, logs, config references, and deployment metadata.
4. Confirm no secret leakage in evidence.
5. Execute rollback plan.
6. Validate service returns to observe or paper mode only.
7. Document gaps and remediation owners.

## Evidence References

Record non-secret links or IDs only. Do not paste credentials, tokens, wallet material, private URLs with embedded credentials, or raw logs containing sensitive values.
